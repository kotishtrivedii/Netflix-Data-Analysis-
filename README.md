# 📖 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on a Netflix-style movie dataset containing **9,827 movies**. Using Python, the raw dataset is cleaned, transformed, and analyzed to identify patterns in movie popularity, ratings, genres, vote counts, and release trends. The processed data is further visualized using **Matplotlib**, **Seaborn**, and an **interactive Tableau Dashboard** to generate actionable insights.

# ▶️ Getting Started

## Clone Repository

```bash
git clone https://github.com/kotishtrivedii/netflix-data-analysis.git
```

## Navigate to Project

```bash
cd netflix-data-analysis
```

## Install Dependencies

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

## Launch Notebook

```bash
jupyter notebook
```

or upload `NETFLIX.ipynb` to **Google Colab** and run all cells.
